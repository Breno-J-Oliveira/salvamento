## Brand & Style

This design system serves a specialized platform connecting emerging cybersecurity talent with high-impact security operations, defense contractors, and forward-thinking enterprises. It bridges offensive vulnerability analysis (Red Team) and defensive resilience operations (Blue Team) into a unified discipline (Purple Team).

The aesthetic unites modern high-performance interfaces with tactical telemetry:
- **Style Archetype:** Modern Cyber-Tactical with Refined Glassmorphism. Deep, layered zinc and obsidian grounds paired with precise structural grids, micro-etched dividers, and vibrant, luminous chromatic accents.
- **Tone:** Authoritative, vigilant, highly technical, and empowering. It rejects cartoonish tropes while embracing legitimate technical iconography: packet streams, CVE metrics, CTF flags, and telemetry nodes.
- **Audience:** Junior analysts, security researchers, penetration testers, SOC engineers, CTF participants, and technical talent evaluators who value precision, proof-of-work validation, and data density.

## Colors

The palette directly models real-world cybersecurity team topologies:

- **Primary (`#A855F7` / Vibrant Purple):** The convergence of offensive and defensive domains—representing Purple Team coordination, unified verified scores, platform actions, and core interactive states.
- **Secondary (`#3B82F6` / Electric Blue):** Represents Blue Team disciplines (Defensive Operations, SIEM/SOC analytics, incident response, packet defense, and hardening protocols).
- **Tertiary (`#EF4444` / Crimson Red):** Represents Red Team disciplines (Offensive engineering, adversary emulation, CTF pwnage, exploits, and CVE alerts).
- **Neutral Surface Foundation (`#090D16`, `#0F172A`, `#1E293B`):** Deep, cold obsidian and slate layers calibrated to eliminate optical fatigue during prolonged triage, CTF events, and candidate dossier reviews.
- **Semantic Data Channels:**
  - `Warning / Gold` (`#F59E0B`): Flag submissions pending verification and vulnerability triage.
  - `Success / Terminal Green` (`#10B981`): Exploit validated, test passed, zero critical alerts.
  - `Text Hierarchy`: Crisp White (`#F8FAFC`) for primary headers, Cool Platinum (`#94A3B8`) for body telemetry, and Muted Cyan-Slate (`#475569`) for metadata and secondary labels.

## Typography

The typographic hierarchy enforces immediate legibility under information-dense conditions:

- **Primary Display & Headlines (Plus Jakarta Sans):** Geometric clarity with sculpted modern terminals provides punchy, high-trust clarity for hero sections, verified match percentages, and dossier headers.
- **Interface & Operational Prose (Inter):** Highly legible across varied pixel densities with optimal aperture definitions, powering evaluation notes, candidate bios, and role criteria.
- **Telemetry, Exploits, and CTF Data (JetBrains Mono):** Applied systematically to all raw data artifacts: CVE indexes, hashes, terminal input/output, scoreboard ranks, score percentages, and skill tags. Monospaced elements bring authentic command-line authority to proof-of-work artifacts.

## Layout & Spacing

The layout is constructed on an adaptable 12-column fluid grid calibrated for tactical telemetry dashboards, recruiter search filters, and multi-pane candidate evaluations:

- **Desktop (1200px+):** 12 columns with 1.25rem (20px) gutters and 2rem outer boundaries. Dashboard layouts use fixed 280px tactical navigation sidebars, fluid candidate feeds, and 360px contextual telemetry panes (for radar charts and verification logs).
- **Tablet (768px - 1199px):** 8 columns with 1rem gutters and 1.5rem margins. Contextual side panels convert to slide-over drawers; metrics collapse from multi-column rows into 2x2 modular matrixes.
- **Mobile (< 768px):** 4 columns with 0.75rem gutters and 1rem margins. Radar charts and CTF proof feeds reflow sequentially. Critical action bars (e.g., "Schedule Technical Screen", "Download Write-Up") lock to the bottom edge with a high-blur backdrop.
- **Density Scaling:** Monospaced data displays and scoreboard feeds utilize `space-xs` and `space-sm` for dense, scannable terminal listings, while profile intros and application cards utilize `space-md` through `space-xl` for breathing room.

## Elevation & Depth

Visual hierarchy is maintained through subtle luminescence, structural translucency, and dark atmospheric layering rather than harsh dropshadows:

- **Canvas Base Layer (`#090D16`):** The terminal canvas ground. Features an ultra-subtle, low-opacity (2%) micro-grid overlay (16px spacing) to evoke digital engineering workspaces.
- **Surface Layer 1 (`#0F172A` at 85% opacity with 12px blur):** Base container cards, search boards, and inactive panels. Edges are framed with a 1px boundary of `rgba(255, 255, 255, 0.07)`.
- **Surface Layer 2 (`#1E293B` at 90% opacity with 16px blur):** Hover states, interactive overlays, modals, and telemetry popovers. Edges use `rgba(168, 85, 247, 0.25)` or corresponding team color accents.
- **Atmospheric Glow Tiers:**
  - *Purple Core Glow:* `0 0 24px -4px rgba(168, 85, 247, 0.3)` on focal components, primary CTAs, and verified score clusters.
  - *Red Team Glow:* `0 0 20px -4px rgba(239, 68, 68, 0.25)` on offensive security badges, critical exploits, and attack vector indicators.
  - *Blue Team Glow:* `0 0 20px -4px rgba(59, 130, 246, 0.25)` on defensive skill badges, SIEM alerts, and infrastructure hardening metrics.
- **Terminal Glass Inset:** Terminal frames use inset shadows (`inset 0 1px 1px 0 rgba(255, 255, 255, 0.06)`) coupled with deep background absorption to create authentic sunken command-line workspaces.

## Shapes

The design system employs a soft technical geometric radius (`roundedness: 1`), keeping corner treatments precise (0.25rem for micro components; 0.5rem for standard cards; 0.75rem for elevated tactical viewports).

This geometry communicates precision and discipline without the extreme severity of zero-radius brutalism. Terminal windows, telemetry chips, and CTF badges maintain clipped, crisp silhouettes, signaling computational rigor and modern software quality.

## Components

### Buttons
- **Primary (Purple Team Core):** Solid `#A855F7` background, text `#FFFFFF`, font weight 600. On hover, background shifts to `#9333EA` with a `0 0 20px rgba(168, 85, 247, 0.45)` atmospheric glow.
- **Red Team Action (Offensive):** Ghosted background `rgba(239, 68, 68, 0.12)`, 1px border `#EF4444`, text `#FCA5A5`. Glows crimson on hover.
- **Blue Team Action (Defensive):** Ghosted background `rgba(59, 130, 246, 0.12)`, 1px border `#3B82F6`, text `#93C5FD`. Glows electric blue on hover.
- **Utility / Terminal:** `#0F172A` background, 1px border `rgba(255, 255, 255, 0.12)`, text `#94A3B8`, mono font label.

### Chips & Badges
- **CTF & Flag Badges:** Monospace `badge-tag` styling with an icon prefix (e.g., `🚩 [HTB: Pro Lab]`). Features a high-contrast dark fill and a vivid 1px perimeter border.
- **CVE Identification Chips:** Dark slate ground, crimson-tinted text (`#F87171`), with high-precision tracking (e.g., `CVE-2024-3094 [CRITICAL]`).
- **Skill Verification Badges:** Purple gradient border (`#A855F7` to `#6366F1`) enclosing a glowing checkmark glyph with candidate percentile ranking (e.g., `Top 3% Reverse Engineering`).

### Cards & Panels
- **Candidate Dossier Card:** Backdrop-blur glass panel with a 1px top border gradient (`#EF4444` transitioning across `#A855F7` to `#3B82F6`) to visually reinforce the Purple convergence. Houses radar skill distribution, CTF history, and active status tags.
- **Terminal Console Panel:** Darkest canvas ground (`#05080F`), top title bar with mini status dot indicators (Red/Blue/Purple), and integrated code blocks using JetBrains Mono with syntax highlighting.

### Input Fields & Controls
- **Tactical Text Inputs:** Solid `#0B1120` with a 1px border of `rgba(255, 255, 255, 0.1)`. Focus state triggers a 1px `#A855F7` border and subtle purple ambient spread. Placeholder text in muted cyan-slate (`#475569`).
- **Checkboxes & Radios:** Sharp 4px radius, `#0F172A` unchecked with a subtle border. Checked state fills with `#A855F7` and displays an inner high-contrast check glyph or target dot.

### Specialized Data Visualizations
- **Hexagonal Radar Charts:** Blue defense metrics mapped along the right axes, Red attack metrics mapped along the left axes, with an overlapping Purple polygon showing balanced synergy.
- **CTF Scoreboard Tables:** Alternating rows of transparent and `rgba(255, 255, 255, 0.02)` backgrounds, monospaced rank digits, live ping indicator pulses, and instant writeup preview links.
